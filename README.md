## Declaración de uso de Inteligencia Artificial

Durante el desarrollo de este proyecto se utilizaron herramientas de Inteligencia Artificial como apoyo en determinadas actividades del proceso de desarrollo.

Entre las herramientas utilizadas se encuentra **Claude AI**, que fue empleado como apoyo para realizar algunas configuraciones de las pantallas de la aplicación, sugerir ajustes en la interfaz gráfica y orientar en aspectos específicos de la estructura del código.

La Inteligencia Artificial se utilizó únicamente como herramienta de asistencia. El equipo de desarrollo fue responsable de revisar, adaptar, implementar y validar las configuraciones y modificaciones realizadas, así como del desarrollo e integración de los diferentes componentes de la aplicación.

Se reconoce el uso de estas herramientas como un recurso complementario para facilitar el aprendizaje y apoyar el proceso de desarrollo del proyecto.
